# Dataset

This project uses the **UCI Online Retail** dataset by Daqing Chen.

- UCI dataset page: https://archive.ics.uci.edu/dataset/352/online+retail
- DOI: https://doi.org/10.24432/C5BW33
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)

The repository documents and publishes the processing logic and selected derived outputs used in the Description Recovery & Validation stage. The original dataset can be obtained directly from UCI using the source above.

Dataset citation:

Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33
